Copy feedback icons now have at least 3:1 contrast in the default themes, also on hover, and a repeat copy within 1.5 seconds shows and announces the result again, also when the copy fails. "Clear All" and disclaimer links use the same accessible link color as other text links. Explorer links no longer contain `//` when the chain's explorer URL ends with a slash, and long explorer names in the account modal wrap centered with padding. Recent transaction rows no longer read the status icon's name to screen readers. The "Wrong Network" button no longer draws the light 1px ring of the connect button on its red fill, so its corners are crisp. The network modal now says "Your wallet is on a network this app doesn’t support. Switch to a network below, or disconnect." instead of "Wrong network detected, switch or disconnect to continue."
