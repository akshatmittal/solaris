Copy feedback icons now have at least 3:1 contrast in the default themes, also on hover, and a repeat copy within 1.5 seconds shows and announces the result again. "Clear All" and disclaimer links use the same accessible link color as other text links. Recent transaction rows no longer read the status icon's name to screen readers.
